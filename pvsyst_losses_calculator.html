Irradiance losses

—›

IAM uses the ASHRAE model F = 1 − b₀·(1/cosθ − 1) with b₀ = 0.05 by default; the typical annual loss for a fixed tilted plane is 2–3%. Soiling: 2–3% temperate climate, 4–6% dusty desert sites without regular cleaning.

Thermal loss — U-value model

—›
Average cell temperature: — °C Thermal loss: — %

PVsyst model: T cell = T amb + G·α·(1−η)/(Uc + Uv·v) with absorptivity α = 0.9. Use production-weighted (midday) averages, not daily means. The values you enter in PVsyst are Uc and Uv themselves — the loss % here is only for this diagram's estimate.

Module & array losses

—›

Module quality: PVsyst's default rule is a quarter of the tolerance spread; for 0/+3% sorted modules that gives −0.75% (a negative value is a gain). LID: 1–2% for mono PERC, 0–0.5% for TOPCon/HJT. Mismatch: PVsyst default 2% (modern binned modules 0.5–1%). Ageing loss for year N = rate × (N−1).
